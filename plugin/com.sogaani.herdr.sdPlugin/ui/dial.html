Agent dial

The dial shows the agent that has Herdr's focus. Rotate to move the focus to the previous / next agent (blocked agents first). Press and hold run the actions chosen below (defaults: approve / decline). Tap the screen: focus.

Press behaviour

Approve and Decline type the keys above only while the agent is blocked (Safety); otherwise the pane is focused. Keys use Herdr names such as enter, esc, 2, down enter.

Hosts

Passwords are stored in Stream Deck's settings file in plain text. Prefer a key or ssh-agent when you can.
